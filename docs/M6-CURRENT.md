## 主要操作

- `W/S/A/D`：镜头上/下/左/右移动；鼠标滚轮缩放。
- 左键：选择或框选；`Shift` + 左键追加选择；拖动小队徽记下达移动，松到敌军时攻击。
- 右键：智能移动、攻击或进入己方据点驻防。
- `F`：攻击移动；`X`：停止；`B`：打开/关闭建造；数字 `1` 至 `7`：选择建造项或城门升级。
- `Esc`：暂停菜单；`R`：胜负后重新开始当前地图；`Q`：退出。
- 选中己方城镇后，可在底栏建设贸易、征募或要塞专精，也可降级后重新选择。
