# 城邦争霸单机试玩版路线

## 目标与边界

Windows 键鼠、玩家对战 AI、能够重复完成整局的单机试玩版。围绕占领城镇、收入、建造训练、战斗扩张、摧毁主城推进。首版两张地图，保留步兵、弓兵、骑兵和现有建筑体系。

按 M0 → M4 验收，不设硬日期。前阶段未验收，不启动下一阶段。用户负责玩法取舍和最终试玩验收，开发助手负责实现、测试、证据与文档。短时启动不代表整局通过。

## 管理约定

- 本文件是唯一任务清单。状态仅为待办、进行中、待验收、完成；同时进行的开发任务最多一个。
- P0：崩溃或无法完成一局；P1：当前阶段必需；P2：后续提升。依次处理。
- 每项记录目的、改动、依赖、验收。超过两个开发时段继续拆分。代码完成先进入待验收，证据通过后完成。
- 新点子先排入候选；插入当前阶段必须是必要问题，并移出等量非必要任务。
- 每项完成后记录结果和下一步；阶段结束复核剩余范围。保留注释和 TODO，不静默删除任务。
- Git 保存源码、配置、文档和 LFS 资产；每个已验收里程碑保存标签、安装包和独立资产备份。未经验收不打完成标签。

## 验证与版本规则

规则改动更新相关 RTS.Strategy 自动化测试；交互改动在 PIE 人工验收；每个阶段必须在独立打包程序中完成整局。性能固定开发机、1280×720 窗口、相同画质和场景，记录实际单位规模及帧时间再比较，不凭启动成功宣称流畅。

沿用现有 Strategy 模块、FStrategyOrder 与数据资产；不预建插件框架或通用技能系统，不为本路线新增公共 API。
