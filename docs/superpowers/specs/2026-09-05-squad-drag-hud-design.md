# 小队头顶拖拽 HUD 设计

## 目标

为每支己方存活小队提供始终可见的头顶 HUD 控件。玩家可直接拖动控件向任意地面下达移动命令，或拖到可见敌军、敌方建筑上自动下达集火攻击命令。交互参考《Takeover》的小队拖拽操作，同时复用项目现有的小队、选择、队形、寻路和战斗规则。

## 范围

首版仅支持 Windows 键鼠和玩家阵营。敌方小队不显示可拖拽控件。不增加第三方插件、图片资源、网络复制、触摸操作、路径曲线编辑或编队朝向调整。

## 架构

采用 HUD 投影控件，不为小队创建 `WidgetComponent`：

- `AStrategySquad` 提供整队生命比例、头顶世界坐标和存活状态。
- `AStrategyHUD` 将小队头顶坐标投影到屏幕，绘制徽记、整队生命条、拖拽箭头和落点反馈。
- `AStrategyPlayerController` 统一处理徽记命中、拖拽状态、目标识别、选择变更和命令下发。
- 命令继续使用现有 `FStrategyOrder`、`AStrategySquad::IssueOrder()` 和单位移动战斗流程。

HUD 投影控件保持固定屏幕尺寸，避免世界空间 Widget 随镜头缩放或与现有鼠标输入竞争。

## 视觉表现

- 徽记锚点位于小队中心上方 260 cm。
- 默认直径 34 像素；悬停、选中或拖动时直径 42 像素。
- 使用现有玩家阵营蓝色，以简单几何轮廓区分步兵、弓兵和骑兵，不显示成员数量或文字。
- 徽记下方绘制整队生命条。
- 拖到地面时绘制绿色方向箭头和落点圆环。
- 拖到合法敌方目标时绘制红色方向箭头并高亮目标。
- 离开屏幕、已经全灭或非玩家阵营的小队不绘制可交互徽记。

## 整队生命

单位提供当前生命比例或当前生命与初始生命查询。小队的生命比例按仍存活成员的当前生命总量除以小队初始总生命量计算，单位死亡不会改变小队的生命上限。

## 输入状态与优先级

### 普通状态

1. 左键按在己方小队徽记上时，控制器记录源小队并进入候选拖拽状态，该次输入不启动框选。
2. 鼠标移动达到 6 像素后进入正式拖拽，并显示方向箭头。
3. 松开左键时根据光标下目标生成命令。
4. 未超过拖拽阈值时视为点击，仅执行选择。

### 选择规则

- 拖动已经属于当前选择的小队时，命令发送给全部已选小队。
- 拖动未选小队时，先清除原选择并仅选择该小队，然后只向该小队发送命令。
- 单击徽记选择该小队。
- `Shift` 单击徽记沿用现有追加或取消选择行为。

### 命令转换

- 松到任意可命中地面：发送 `EStrategyOrderType::Move`，目标为地面命中点。
- 松到当前可见、存活、非己方的 `IStrategyDamageable`：发送 `EStrategyOrderType::AttackTarget`，目标为该 Actor。
- 敌军或敌方建筑不可见时不作为攻击目标，按光标对应地面处理。

### 模式冲突

普通建筑放置和城墙拖拽模式优先于小队 HUD。处于建造模式时徽记继续绘制，但不接受点击或拖拽。右键命令、左键框选和现有键盘命令在非 HUD 拖拽状态下保持原行为。

## 控制器数据流

控制器每帧获取所有玩家存活小队的投影徽记信息，并按鼠标距离选择最靠近且在命中半径内的徽记。按下时缓存源小队和屏幕起点；拖动时持续通过现有光标射线查询更新地面或敌方目标；松开时构造一个 `FStrategyOrder` 并发送给确定的接收小队集合，随后清除拖拽状态。

HUD 只读取控制器暴露的拖拽显示状态，不自行改变选择或发送命令，避免绘制逻辑持有游戏规则。

## 测试与验收

### 自动化测试

- 徽记圆形命中范围及最近徽记选择。
- 已选源小队返回全部已选接收者，未选源小队只返回自身。
- 可见敌方伤害对象转换为 `AttackTarget`，普通地面转换为 `Move`。
- 满血、受伤和减员情况下的整队生命比例。
- 建造模式下禁用小队 HUD 交互。

### 构建验证

- RTSEditor Win64 Development 编译成功。
- 完整 `RTS.Strategy` 自动化测试无失败、Fatal 或 Assert。
- Windows Development 完成 Cook、Stage、Pak 和 Archive。
- 打包程序加载默认遭遇战地图并稳定运行至少 12 秒。

### PIE 人工验收

- 单击和 `Shift` 单击徽记正确选择小队。
- 拖动未选小队只移动该小队。
- 拖动多选中的任意小队移动全部已选小队。
- 拖到地面显示绿色反馈并保持队形移动。
- 拖到可见敌军或敌方建筑显示红色反馈并集火。
- 建筑放置、城墙拖拽、框选和右键命令不与徽记拖拽冲突。
- 缩放和平移镜头时，徽记位置跟随小队且屏幕尺寸保持稳定。
