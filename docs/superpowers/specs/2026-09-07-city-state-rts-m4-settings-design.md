# M4-02 音量与显示设置设计

## 1. 目标与范围

为 Windows 单机原型增加可持久化的总音量和显示设置。玩家在战局中按 `Esc` 打开暂停界面，能够继续游戏、进入设置或退出游戏；设置在点击“应用并返回”后立即生效，并在重新启动打包程序后保留。

本项只包含总音量、窗口模式、分辨率和整体画质预设。不增加背景音乐、分类音量、逐项画质参数、按键重映射、语言设置或独立主菜单。

## 2. 交互流程

### 2.1 暂停页

- 战局运行时按 `Esc`：暂停游戏并打开暂停页；鼠标沿用 RTS 战局中始终可见的行为。
- 暂停页显示“继续游戏”“设置”“退出游戏”。
- 点击“继续游戏”或在暂停页再次按 `Esc`：关闭菜单并恢复游戏输入。
- 点击“设置”：保持暂停并切换到设置页。
- 点击“退出游戏”：直接退出当前程序，不增加二次确认框。
- 比赛已结束时仍可打开菜单；关闭菜单不会改变已结束的比赛状态。

### 2.2 设置页

- 总音量：`0%` 至 `100%`，步进 `5%`。
- 窗口模式：窗口、无边框全屏、独占全屏。
- 分辨率：读取当前系统由 UE 返回的可用分辨率，去重后按像素面积排序。
- 画质预设：低、中、高、史诗，分别映射 UE 整体画质等级 `0` 至 `3`。
- “应用并返回”：应用显示设置和总音量，保存到用户配置，然后返回暂停页。
- “放弃并返回”：丢弃本次草稿并返回暂停页。
- 设置页按 `Esc`：等同“放弃并返回”。

首次运行使用当前桌面分辨率、无边框全屏、史诗画质和 `100%` 总音量。后续运行加载上次成功保存的值。

## 3. 架构

### 3.1 用户设置

新增 `UStrategyGameUserSettings : UGameUserSettings`。父类继续负责分辨率、窗口模式、整体画质及 `GameUserSettings.ini`；子类只增加 `Config` 属性 `MasterVolume`，默认值为 `1.0f`。

总音量通过 `FApp::SetVolumeMultiplier` 作用于全部当前音效。设置对象初始化和应用非分辨率设置时都同步该倍率，使启动加载与运行时修改使用同一入口。`DefaultEngine.ini` 的 `GameUserSettingsClassName` 指向项目子类。

### 3.2 暂停与设置控件

新增 `UStrategyPauseMenu : UUserWidget`，以纯 C++ 构建轻量 UMG 控件树，不引入新的 Blueprint 资产。控件内部维护 `Pause` 与 `Settings` 两页；打开设置页时从 `UStrategyGameUserSettings` 读取已保存值并建立草稿，UI 操作只修改草稿。

“应用并返回”把草稿写入设置对象，依次设置分辨率、窗口模式、整体画质与总音量，再调用 UE 的应用和保存接口。“放弃并返回”重新读取当前设置，不写入磁盘。

### 3.3 玩家控制器

`AStrategyPlayerController` 在本地玩家开始游戏时创建并持有唯一暂停菜单。菜单关闭时保持现有 RTS 输入与可见鼠标；菜单打开时取消框选和建造预览、暂停世界，并切换为 `UIOnly` 输入模式。暂停控件自身处理 `Esc`，从而保证菜单打开期间 RTS 指令不会穿透到战场。

控制器只管理菜单生命周期和暂停状态；具体设置值、显示项和按钮回调留在暂停菜单中，现有移动、选择、建造、训练与战斗输入不改变。

## 4. 显示应用与失败行为

设置页只列出 UE 报告为支持的分辨率，并保留当前分辨率作为候选，因此正常输入不会产生无效尺寸。应用前保存上一组分辨率和窗口模式；若 UE 应用后的状态不是请求值，则立即恢复上一组显示设置，并且不把失败值保存到磁盘。总音量和画质仍按本次有效草稿保存。

不增加倒计时确认框，也不静默选择另一个分辨率。代码和配置缺失时允许引擎明显失败，不增加通用回退层。

## 5. UI 表现

菜单为屏幕中央固定宽度面板，使用现有 HUD 的深蓝半透明背景、金色标题、白色正文和高亮按钮。暂停页保持短而明确；设置页每行一个标签和一个控件，总音量同时显示百分比。

控件支持鼠标点击与拖动。分辨率变化后由 UMG 自动适配视口，面板保持居中。菜单打开时隐藏 Canvas HUD 的框选矩形和临时指令交互，但战场 HUD 可保留为背景信息。

## 6. 测试与验收

自动化测试采用针对性测试，不重复完整玩法套件：

- 总音量默认值为 `1.0f`，设置值限制在 `0.0f` 至 `1.0f`。
- 四个整体画质名称正确映射到 UE 等级 `0` 至 `3`。
- 三种窗口模式名称正确映射到 UE 窗口模式。
- 设置草稿在“放弃”后不改变已保存设置。
- 编辑器 Development 构建通过。
- Windows M4-02 候选打包成功并能独立启动。

人工验收：

1. 战局中按 `Esc`，确认世界暂停且菜单可用。
2. 依次调整总音量、窗口模式、分辨率和画质，点击“应用并返回”。
3. 关闭并重新启动程序，确认四类设置保持。
4. 修改设置后选择“放弃并返回”，确认原设置不变。
5. 确认设置菜单打开期间无法下达移动、攻击或建造命令。
