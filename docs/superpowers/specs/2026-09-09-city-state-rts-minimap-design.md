# 《城邦争霸》战术小地图设计

## 目标

为现有单人遭遇战 HUD 增加低成本战术小地图。玩家可以通过小地图观察已获知的战场信息、移动摄像机，并向已选小队下达移动或攻击命令。小地图必须复用现有战争迷雾和命令规则，不泄露不可见敌军信息，也不能干扰战场框选、HUD 徽记拖动、暂停菜单和设置菜单的鼠标输入。

## 范围

本阶段包含：

- 右下角战术小地图及响应式尺寸。
- 简化地形、战争迷雾、据点、建筑、小队、驻防状态和摄像机视野框。
- 左键点击或拖动小地图移动摄像机。
- 右键点击地面移动，右键点击当前可见敌军攻击。
- 固定北向与跟随摄像机两种方向模式。
- 设置菜单切换和持久化，默认固定北向。

本阶段不包含小地图缩放、折叠、信号标记、单位框选、攻击移动快捷键或 `SceneCapture2D` 实时三维画面。

## 总体方案

采用自定义 C++ UMG 控件 `UStrategyMinimapWidget`。控件缓存简化战术底图，并动态绘制迷雾、图标和摄像机视野框。世界坐标与小地图坐标的转换集中在独立的 `FStrategyMinimapProjection` 中。小地图只负责把鼠标输入解释为世界位置或可见目标，实际摄像机移动及小队命令继续调用现有 Pawn 和 PlayerController 接口。

不采用 Canvas HUD 直接实现，以免把控件命中测试继续耦合到现有世界投影 HUD；不采用 `SceneCapture2D`，以避免额外渲染开销和重复实现迷雾可见性。

## 组件职责

### `UStrategyMinimapWidget`

- 由 `UStrategyHUDRoot` 创建并放置在右下角操作栏上方。
- 绘制底图、迷雾、据点、建筑、小队、驻防标记和摄像机视野框。
- 处理控件范围内的左键点击、左键拖动、右键点击和鼠标释放。
- 优先消费自身输入，禁止事件继续传递到战场框选或其他 HUD 拖动逻辑。
- 只读取游戏状态，不拥有战斗、迷雾或命令规则。

### `FStrategyMinimapProjection`

- 使用地图定义中的 `FogMin` 和 `FogMax` 将二维世界位置映射到小地图局部坐标。
- 提供世界到小地图、小地图到世界的互逆转换。
- 固定北向模式不旋转坐标。
- 跟随摄像机模式围绕地图中心旋转显示坐标，并对输入执行相反旋转。
- 使用同一变换处理底图、迷雾、图标、视野框和鼠标输入，防止旋转模式产生偏移。

### `AStrategyPlayerController` 与 `AStrategyPawn`

- Pawn 提供按世界 XY 位置设置摄像机中心的入口，并继续执行现有摄像机边界限制。
- PlayerController 接收小地图右键请求。
- 点击当前可见敌军图标时，复用主视图现有智能攻击命令入口。
- 其他位置复用现有移动命令入口。
- 没有已选小队时不执行右键命令。

### 战争迷雾与设置

- 现有迷雾模块仅增加小地图所需的只读网格或纹理访问，不创建第二套更新循环。
- `UStrategyGameUserSettings` 增加小地图方向枚举，取值为 `NorthUp` 和 `FollowCamera`。
- 默认值为 `NorthUp`；玩家在设置中修改后立即应用并持久保存。

## 地图范围与布局

小地图使用扩大后的 `32000×28000 cm` 可视地图范围，即地图定义中的 `FogMin=(-16000,-14000)` 与 `FogMax=(16000,14000)`。摄像机仍使用较小的合法移动范围，因此从小地图点击边缘时，Pawn 会把摄像机中心限制到允许范围。

小地图默认约为 `300×240 px`，放置在右下角、底部操作栏上方。低分辨率下按视口比例等比缩小，保持地图宽高比，并避免覆盖城镇管理面板。固定北向模式显示 `N` 方向标记。

## 绘制与可见性

底图使用缓存的简化战术图，不实时渲染三维世界。底图只表达地图边界、主要地面色块、河流或道路轮廓。动态层按以下顺序绘制：底图、迷雾、据点与建筑、小队与驻防标记、摄像机视野框和方向标记。

可见性规则：

- 己方小队、建筑和主城始终显示。
- 敌方小队、建筑和主城仅在当前视野内显示，离开当前视野后立即隐藏，不保留最后位置。
- 中立或已探索城镇持续显示；未探索城镇不显示归属详情。
- 驻防小队仍显示，并在对应城镇图标附近附加驻防标记。
- 未探索区域为黑色，已探索但当前不可见区域为暗色，当前可见区域透明。
- 图标保持固定屏幕像素尺寸，不随主摄像机缩放改变；位置重叠时允许轻微错位。

摄像机视野框由当前摄像机视口四角与地面的交点转换得到。移动和缩放摄像机时实时更新。跟随摄像机模式会对底图、迷雾、图标和视野框应用同一旋转。

## 输入流程

### 左键移动摄像机

左键按下时，将小地图局部位置转换为世界 XY，并立即定位摄像机。按住左键移动时持续重复该过程。摄像机位置由 Pawn 限制在现有边界内。

鼠标释放、移出控件、暂停或打开设置时结束拖动。恢复游戏或关闭设置后，现有菜单流程继续把输入模式和焦点交还游戏视口，避免左右键失效。

### 右键智能命令

右键按下时先在小地图可见图标中执行命中测试：

1. 命中当前可见敌军图标时，向全部已选小队发送现有攻击命令。
2. 未命中敌军时，将位置转换为世界地面位置，向全部已选小队发送现有移动命令。
3. 没有已选小队时结束处理，不下达命令。

小地图不复制伤害、寻路、目标合法性或编队规则。敌军命中测试的数据源与小地图绘制列表相同，保证不可见敌军既不显示也不能被点击。

## 错误处理边界

按照项目的始终成功路径，小地图假定 HUD、地图定义、迷雾和玩家控制器已正常创建。实现不增加静默回退、第二套默认地图范围或重复输入恢复逻辑。所需对象缺失时允许引擎明显暴露配置错误。

## 验证

自动测试限于稳定且容易回归的纯规则：

- 固定北向世界坐标与小地图坐标的正反转换。
- 跟随摄像机模式的旋转与逆旋转转换。
- 己方、可见敌方、不可见敌方及城镇的显示规则。
- 小地图右键命中敌军时攻击、其他位置移动、无选择时不下令。

实现完成后只运行一次相关 UI 与规则测试。手动检查 `1280×720`、`1920×1080`、`1920×1200` 和当前超宽屏布局，并验证：

- 左键点击与拖动摄像机。
- 两种方向模式及设置持久化。
- 右键移动和可见敌军攻击。
- 暂停、继续、打开和关闭设置后的鼠标输入。
- 未探索及当前不可见敌军不会通过小地图泄露。
- 驻防小队与摄像机视野框显示正确。

最终只执行一次 Windows 打包和一次启动冒烟测试。

## 完成标准

玩家能在小地图上可靠地观察允许获知的战场状态、移动摄像机并下达移动或攻击命令；两种方向模式显示和输入位置一致；暂停及设置流程不造成鼠标失效；小地图在目标分辨率下不遮挡主要 HUD，且不会泄露战争迷雾中的敌军信息。
